## ✨ Features

- 🟥 **Color changer**: press **Start** and the background color changes continuously while a timer is displayed. Press **Stop** to freeze both the color and the timer.
- 🔘 **Window mover**: four buttons (**Up**, **Down**, **Left**, **Right**) that move the window in the matching direction.

## 🚀 Getting Started

**Requirements:** Windows, Visual Studio, and the .NET Framework 4.5 (or newer) developer pack.

```bash
git clone https://github.com/USERNAME/REPO.git
```

1. Open the `.sln` file in Visual Studio.
2. Press `F5` to build and run.
